# LifeVault - Encrypted Personal Analytics Platform

Privacy-first personal analytics with face recognition on Raspberry Pi 5.

## Features
- 🔐 End-to-end encryption
- 👤 Face recognition & authentication
- 📊 Personal analytics tracking
- 🌐 Web app (React + TypeScript)
- 📱 Mobile apps (React Native + Flutter)
- 🔄 Offline support
- 🌙 Dark mode
- 🔔 Push notifications

## Tech Stack
- Backend: Python (FastAPI)
- Database: PostgreSQL
- Web: React + TypeScript + Vite
- Mobile: React Native + Flutter
- Hardware: Raspberry Pi 5 + 5MP Camera
